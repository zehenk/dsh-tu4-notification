## 4. 修复内容

### 4.1 修复中文 JSON 解析问题
**问题**：PowerShell 5.1 的 `ConvertFrom-Json` 对包含中文字符的 JSON 数组解析失败
**修复方案**：使用手动解析替代 `ConvertFrom-Json`，兼容 PowerShell 5.1

**修复代码**：
```powershell
# 修复前
$optionsArray = $Options | ConvertFrom-Json

# 修复后
$optionsArray = @()
$trimmed = $Options.Trim('[', ']')
if ($trimmed) {
    # Split by comma and trim each option, removing quotes
    $optionsArray = $trimmed -split ',' | ForEach-Object { 
        $_.Trim().Trim('"').Trim("'") 
    } | Where-Object { $_ -ne '' }
}
```

**修复文件**：`dsh-tu4-notification/notify.ps1` (第 320-345 行)
